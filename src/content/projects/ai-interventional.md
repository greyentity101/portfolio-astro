Research project providing real-time AI overlay for interventional radiology procedures. Processes live fluoroscopy feeds to highlight anatomical landmarks and guide needle placement — improving accuracy while reducing radiation exposure.

Features:
- Real-time frame processing at 30fps
- Anatomical landmark detection with PyTorch
- Dose-aware processing pipeline
- DICOM-integrated workstation UI
