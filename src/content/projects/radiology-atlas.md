A zero-dependency DICOM parser built in TypeScript that runs entirely in the browser. Supports loading, viewing, and annotating DICOM files offline — no server needed. Designed for clinicians who need fast, private access to medical imaging data.

Features:
- Pure TypeScript DICOM parser (~2KB gzipped)
- Offline-first with service worker caching
- Annotation tools with exportable reports
- PWA installable on any device
- Zero external dependencies
